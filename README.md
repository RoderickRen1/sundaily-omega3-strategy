# 圣迪乐 Omega-3 会员运营战略体系 V1.0

[打开战略网站](https://roderickren1.github.io/sundaily-omega3-strategy/) · [战略一张图](https://roderickren1.github.io/sundaily-omega3-strategy/#summary)

从自主品牌会员经营到消费者增长中心。网站包含战略总览、九大章节、14 个行业案例、六大经营体系、四大增长飞轮、财务模拟器、组织模式与阶段切换，以及管理层汇报模式。

## 本地预览

在项目目录运行 `python3 -m http.server 8080`，访问 `http://localhost:8080/`。网站采用静态 HTML、CSS 和 JavaScript，无需安装依赖或构建。GitHub Pages 从 `main` 分支根目录发布。

- `content.js` 维护战略数据、案例来源状态及模拟器演示参数。
- `app.js` 实现章节呈现、交互图、模拟器、导航和汇报模式。
- `style.css` 维护设计系统与响应式布局。
- `assets/` 存放站点图标和 ImageGen 生成的首屏蛋形雕塑。

已取得的官方资料可在相应行业案例详情中查阅，其他机制注明待复核。财务数字采用演示假设。
